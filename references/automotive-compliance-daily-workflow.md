# 自动驾驶合规每日情报工作流

> 独立 cron job，每天自动执行。产出归档到 `~/wiki/queries/`。

## 执行步骤

### 1. 并行搜索（6 个关键词独立搜索）

同时发起以下 6 个 `web_search` 调用（limit=10 每个）：

| # | 关键词 | 目标领域 |
|---|--------|---------|
| 1 | `"自动驾驶 合规"` | 整体政策/法规 |
| 2 | `"智能网联 数据安全"` | 车联网数据安全 |
| 3 | `"高精地图 审图"` | 地图审核/测绘 |
| 4 | `"车联网 数据安全"` | 车联网网络安全 |
| 5 | `"测绘资质 智能网联"` | 测绘资质管理 |
| 6 | `"汽车数据安全管理"` | 汽车数据合规 |

### 2. 读取背景知识库

`read_file(path='~/wiki/queries/automotive-compliance-solution.md')` — 获取现有法规体系、合规架构、技术标准等背景信息。

### 3. 对比昨日产出

`read_file(path='~/wiki/queries/automotive-compliance-daily-YYYY-MM-DD.md')` — 读取上一期报告，避免重复，标注新进展。

### 4. 深度阅读关键文章

对搜索结果中最新、最重要的文章，使用 `browser_navigate` 获取全文内容。重点关注：
- 新发布的政策文件/标准
- 监管部门的通知/问答
- 行业处罚案例细节
- 地图审核/测绘资质新规

### 5. 编译报告

按以下结构输出 Markdown 报告：

```markdown

title: 每日情报 | 自动驾驶合规 · YYYY-MM-DD
date: YYYY-MM-DD

---
```

### 6. 存档

```bash
# 保存到 wiki
write_file(
  path='~/wiki/queries/automotive-compliance-daily-YYYY-MM-DD.md',
  content=report_content
)

# git commit + push
cd ~/wiki
git add queries/automotive-compliance-daily-YYYY-MM-DD.md
git commit -m "daily: 自动驾驶合规情报 YYYY-MM-DD — 本期核心事件"
git push
```

## 来源筛选标准

只保留以下 5 类内容，其余过滤：

1. **政策文件发布/修订** — 法律法规、部门规章、规范性文件的新发布或修订
2. **行业标准征求意见/发布** — 国标/行标/团标的征求意见稿、报批稿、正式发布
3. **监管部门的通知/问答/工作会议** — 工信部、自然资源部、交通运输部、网信办、公安部等发布的政策解读、答记者问、工作会议部署
4. **企业合规处罚/整改案例** — 数据安全、测绘资质、地图审图等方面的处罚/整顿
5. **图商/地图审图相关动态** — 高精地图审图号、导航电子地图资质、地图合规标准

## 重点关注的监管部门

| 部门 | 关注领域 |
|------|---------|
| **自然资源部** | 地图审核、测绘资质、地理信息安全管理（139号文） |
| **工业和信息化部** | 网络安全、数据安全、智能网联汽车准入、车联网安全 |
| **交通运输部** | 道路运输安全、自动驾驶运输服务、车辆安全 |
| **国家互联网信息办公室** | 数据出境、个人信息保护、网络安全审查 |
| **公安部** | 智能网联汽车道路测试与示范应用通行规范（GA/T 2388） |
